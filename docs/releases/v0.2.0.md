piDeck v0.2.0 improves agent session freshness, provider usage reporting, and the Agents and Usage views.

## Agent sessions

- Track real session activity separately from discovery/synchronization. Repeated startup or background discovery no longer keeps inactive sessions alive indefinitely.
- Discover recently active local sessions over a 24-hour window and hide sessions after 24 hours without real activity. Recently modified sessions appear working; older discovered sessions appear idle.
- Prefer available public session titles and summaries over opaque identifiers. Prompt and transcript bodies are not used as tile labels.
- Show subagents beneath their parent with a clearer visual hierarchy and dashed elbow connectors.

## Provider usage

- Refresh Claude allowance usage once at launch, including after an earlier failed attempt.
- Record successful fetch time only after a usable sample is returned, so a failed request does not suppress the next refresh.
- Show fetch-status notes when usage bars are unavailable.
- Expand detailed Usage bars across the available space and use pixel diagonal-stripe meters while retaining the usage color scheme.

## Desktop and documentation

- Fresh desktop installers include content-fingerprinted UI assets, preventing older cached scripts from hiding changes after an upgrade.
- Keep Settings on the left and restore the desktop window's saved size, position, and expanded state.
- The README walkthrough shows all seven example agents without scrolling, followed by a completion celebration, detailed usage, Spotify, and Slack. Garbled README punctuation and dimension symbols are repaired.

## Install or update

Use the Windows x64 setup executable, or choose the Apple Silicon/Intel Mac DMG and move piDeck into Applications. Python and application dependencies are bundled. These are **unsigned builds**: Windows may show an unknown-publisher warning, and macOS may require an explicit Open Anyway exception.

Configuration and credentials remain outside the application bundle and survive upgrades. After updating, open the bottom-left gear and choose **Connect installed agents** to update the copied hook integration. Close any old source-based piDeck instance before opening the installed app if it is still holding the local port.

The source ZIP supports source and Raspberry Pi installations. `SHA256SUMS` covers the downloads; per-platform build manifests record the source commit, interpreter, architecture, dependency versions, and lock hash. Dependency audits accompany the native builds. Checksums provide integrity comparison, not publisher authentication.
