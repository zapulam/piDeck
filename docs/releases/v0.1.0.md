piDeck is a desk display for Raspberry Pi, Windows, and macOS, combining Claude Code, Codex, and Cursor activity with Spotify and Slack.

## Agents and usage

- Drag provider headings to reorder their entire groups, with keyboard controls and a saved order for each display. Same-project chats have distinct fruit sprites and short session labels, and Claude/Cursor subagents identify their parent project.
- Working cards have blue outlines and gentle bouncing sprites, with intermittent pixel thinking bubbles. Idle sprites blink and look around at random intervals.
- Completed turns trigger a brief full-screen celebration with a randomly chosen cowboy hat, graduation cap, baseball cap, or sunglasses. A checkmark remains on the matching session card until acknowledged or work resumes; acknowledgments survive display reloads.
- Session context bars and provider account usage are shown separately. Compact account donuts show the percentage in green below 70%, yellow at 70–90%, and red above 90%. Drag the usage panel to the top, bottom, left, or right; the position is saved on this display. Claude and Codex expose short-window and weekly usage; Cursor shows Included and API usage when its local sign-in is available.
- Startup discovers recently active local sessions and restores available usage samples. Claude/Cursor allowance refreshes use the local sign-in, and access tokens are never sent to the display.
- Claude status-line integration preserves the original command, forwards context and allowance updates, and periodically refreshes. Hook reinstallation preserves saved display tokens. Cursor can refresh an expired local sign-in once.

## Desktop and display

- Resizable Windows and macOS desktop windows run from a clone, with setup scripts, a Windows Start menu shortcut, a macOS app, and optional launch at login.
- Responsive portrait and landscape layouts, software screen rotation, provider groups, and a dedicated Settings page that stays available when all other pages are hidden.
- Spotify playback controls and now-playing progress, Slack DMs and mentions, and full-screen attention alerts.
- The README walkthrough shows the Agents page, an agent completing, then Spotify and Slack, using only mock data and generated artwork.

## Validation and distribution

- Consistent Python module descriptions, section comments, typed function signatures, full argument/return documentation, and single-newline file endings, enforced by a dedicated CI check.
- Python 3.11 and 3.13 tests on Linux, Windows, and Intel macOS; macOS 26 uses Intel runners to avoid ARM runner allocation failures. ARM macOS is not part of this validation matrix.
- Chromium integration checks the websocket UI at four display sizes, plus animation behavior and session completion acknowledgment.
- Source archives include SHA-256 checksums. GitHub build-provenance attestations are produced where supported; GitHub does not support stored attestations for user-owned private repositories. Release automation reruns CI against the exact tagged commit before publishing or explicitly refreshing assets.

## Install or update

Clone or update the repository, then run `scripts/setup-windows.ps1` on Windows or `scripts/setup-macos.sh` on macOS. Re-run the hook installer after updating to copy the latest integration script. Raspberry Pi and desktop setup instructions are in the [README](https://github.com/zapulam/piDeck/blob/v0.1.0/README.md).

The source ZIP is for archival and Raspberry Pi installs; standalone desktop binary ZIPs are not published. **Refreshing v0.1.0 replaces its source archive, checksum manifest, and associated release notes with the contents of the current tagged commit.**
